# 共通ゲーム仕様

49実装を公平に比較できるよう、ルールとUIを共通化します。演出や内部設計は
各エンジンに適した方法を選びます。

## 共通UI

- 論理解像度: 960 × 540、60 fps目標
- 起動直後: 7ゲームの選択メニュー
- 選択: `1`〜`7`、または上下キー + Enter
- プレイ中: ゲーム名、操作、スコアまたは残り時間を常時表示
- 終了後: 勝敗と再プレイ方法を表示
- `Enter`: 終了後に同じゲームを再開
- `Esc`: いつでもメニューへ戻る
- マウス・タッチが主操作のゲームは、ポインター入力にも対応

## 1. Kofun Courier

矢印またはWASDで移動する。追跡する敵に触れず、45秒以内に埴輪を8個集める。
敵に触れるか時間切れで失敗。

## 2. Mound Breaker

左右またはA/Dでパドルを動かす。ボールを落とせるのは3回まで。
5行 × 10列のブロックをすべて壊せば成功。

## 3. Haniwa Tap Patrol

マウスまたはタッチで埴輪を押す。30秒以内に12回押せば成功。
おとりを押すと残り時間が3秒減る。

## 4. Dochicken Sky Dodge

Space、上キー、またはタップで上昇する。上下の障害物や画面端を避け、
10本のゲートを通過すれば成功。

## 5. Neon Kofun Dash

Space、上キー、またはタップでジャンプする。接近する障害物を避け、
30秒生き残れば成功。

## 6. Kofun Orbit

矢印またはWASDでアリーナ内を移動し、Spaceで短距離パルスを放つ。
接近する敵をパルスで退けながら30秒生き残れば成功。

## 7. Kofun Snake

矢印またはWASDで方向転換する。壁や自分の列に当たらず、
埴輪を15個集めれば成功。
