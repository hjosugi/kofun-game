# 実装アーキテクチャ

各エンジンは同じ状態遷移を持ちます。

```text
Menu
  ├─ Courier ─┐
  ├─ Breaker ─┤
  ├─ Tap ─────┤
  ├─ Flap ────┼─> Result ── Enter ──> same game
  ├─ Dash ────┤       └──── Escape ─> Menu
  ├─ Orbit ───┤
  └─ Snake ───┘
```

全モードを1つの小規模プロジェクトへ収めることで、エンジンの初期化コスト、
入力API、描画API、状態管理、ビルド成果物を同じ条件で比較できます。

描画は各エンジンの図形APIを中心にし、素材読み込み失敗がゲーム進行を
止めない構成です。これにより、機能比較とアセット表現を分離しています。
